# Eval data — sources & licenses

All items below were downloaded 2026-10-28 from Pexels or Wikimedia Commons
under the licenses listed. No item comes from YouTube/social media.
Every downloaded file was verified with `file`/`ffprobe`, and the key items
were visually checked from extracted frames / the images themselves.

General rights note: every item is usable in the public submission repo and
the demo video, provided the attribution lines in this file are kept (CC BY /
CC BY-SA items require credit; we credit all sources anyway). CC BY-SA items:
if a file is adapted (cropped/annotated), the adaptation must keep the same
license. Pexels items: usable under the Pexels License (free use, no
attribution required); do not redistribute them as a standalone stock library.
